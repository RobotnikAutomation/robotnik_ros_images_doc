# ROS 1 Examples

These examples show how to use the [basic](../../resources/) Robotnik ROS images.

Each example is described by the **images** it builds and the **services** (i.e. containers) it runs.

- [basic](basic): run a simple publisher and subscriber.
- [generate-debs](generate-debs): generates an image with deb packages from source code repositories.
- [generate-and-install-debs-from-source](generate-and-install-debs-from-source): generates deb packages from a source code repository and installs them in a robotnik base image.
- [rviz-web](rviz-web): creates an image with a web-based RViz interface.
