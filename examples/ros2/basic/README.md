# Basic

This a simple example where you have build a talker-listener example

## Usage

```bash
docker compose up
```

## Images

- **publisher**: derived from robotnik base image, with the minimal publisher example installed.
- **subscriber**: derived from robotnik base image, with the minimal subscriber example installed.

## Services

- **publisher** (ros2-basic-publisher): runs publisher node
- **subscriber** (ros2-basic-subscriber): runs subscriber node
